# Portfolio Website

This is a simple static portfolio website built with HTML, Bootstrap 5, and a small amount of custom CSS/JS.

Files included:
- `index.html` — Main single-page site that contains Home, Resume, Projects, Lab Challenges, and Contact sections.
- `styles.css` — Custom styles for layout and visuals
- `script.js` — Small JS for smooth scrolling and navbar behavior
- `grading_document.md` — Submission template with placeholders for screenshots and link

## Preview locally
Use any static file server. Examples:

Python 3 (built-in):

```bash
# from project root
python3 -m http.server 8000
# then open http://localhost:8000 in your browser
```

Node (http-server):

```bash
npm install -g http-server
http-server -p 8000
```

## Deploy to GitHub Pages
1. Create a GitHub repository and push the project.
2. In repository Settings > Pages, select the `main` branch and the root folder.
3. Save — your site will be available at `https://mnyando.github.io/` for this repo.

## Notes
- Replace placeholder images and profile details in `index.html` with your real photo and links.
- Add screenshots to `grading_document.md` and update the deployed site link before submission.
